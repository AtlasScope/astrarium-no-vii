# ASTRARIUM No. VII

A six-winged intelligence, wound into glass. One turning of the key is one history of the world.

Open `index.html` in a browser. Click the gate. Drag the key clockwise. Cities grow on the wings. The moon keeps time. Then the spring forgets.

## Phone

Open the same `index.html` on your phone (Safari or Chrome). Tap the gate, then **hold WIND**. Drag around the ring clockwise. Tap the glass to enter.

The page detects a phone and switches to a lighter renderer, a thumb-sized wind button, and a layout that fits a portrait screen. It also falls back to WebGL1 if WebGL2 is missing.

## Controls

| Input | Action |
| --- | --- |
| Hold WIND | Wind the spring (phones) |
| Drag around the ring clockwise | Wind the spring |
| Tap the glass | Descend into the being / return |
| Space | Give the spring a turn |
| Enter | Toggle descent |
| R | Restart the aeon |

`?autostart=1` skips the gate. `?shot=1` freezes a late-city frame. `?age=0.34` picks an epoch.

## Epochs

The Unwinding Dark → First Spark → The Molten Psalm → Wings Remember Gold → The City Liturgies → Orbital Covenant → The Long Dimming → Silence of the Spring

## Stack

One HTML file. No frameworks. WebGL2 raymarching, polar-repeated seraph wings, gyroid liturgy, city extrusion, orrery rings, a clock-moon, a music-box sequencer, a grammar of dying myths.
